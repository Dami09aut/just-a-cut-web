# Just A Cut · Web

Web estática para **Just A Cut Studio**, barbería en Santa Cruz de Tenerife (@justacut.studio).

- `index.html`, `styles.css`, `main.js`: sin dependencias ni build.
- La intro es un vuelo en 3D por los paneles LED hexagonales del techo del estudio, dibujado en canvas.
- Reservas: https://cut.yeasyapp.com/LoAVEZ

Para verlo en local: `python3 -m http.server` y abrir http://localhost:8000.
